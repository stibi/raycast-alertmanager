# Alertmanager Changelog

## [Initial Version] - {PR_MERGE_DATE}

- List active alerts from one or more Prometheus Alertmanager instances
- Per-instance summary grid with alert counts by severity
- Group alerts by `alertname` and sort by severity, age or name
- Alert detail view with labels, annotations, receivers and source link
- Create silences: from a form, instantly with your last settings, or by
  picking labels across alerts
- Manage instances with optional basic auth and a connection test
